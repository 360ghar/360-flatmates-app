## 3. Decisions for this pass

In scope: tokens, shared components, dark mode, accessibility, text scale, small and large
phones, localization of hardcoded strings, code rules (mounted checks, logging, no raw errors),
moving logic to controllers, and UI bugs that crash, overflow, lose form data or show dead
controls.

Out of scope (behaviour, product or API decisions; listed for follow-up):
- Visit Confirm is shown to the requester: `VisitItem` has no requester field (backend change).
- Feedback reports do not send app version or device data (new data sent to the backend).
- Moving privacy toggles from the preferences sheet to Privacy and security (information
  architecture change).
- Terms checkbox is checked by default (product and legal decision; a test asserts it).
- Trending neighbourhoods were a hardcoded list: removed as fabricated data (a catalog field can bring
  them back).
- Swipe photo pager takes horizontal drags (interaction change to the deck).
- Icebreaker chips send at once instead of filling the composer (interaction change).
- Edit listing cannot split the saved features back into furnishing, room features and flat
  amenities: all four groups use the `flatmates_listing_amenities` catalog and the server stores
  their union in `features`. Edit mode shows them under room features; saving keeps them. A split
  needs per-group fields in `listing_preferences` (backend change).
- The active nav tab is paper-2 without the e2 shadow: Material `NavigationBar` paints its
  indicator with a plain `ShapeDecoration`, so it cannot cast a shadow without a custom nav bar.

## 5. Maestro smoke (25 September 2026, iOS simulator, seeded co-hunter account)

Before this pass the suite could not pass anywhere: Maestro's `id:` reads only
`Semantics.identifier`, and 48 of the 54 smoke ids were Flutter keys only (CI on `main` failed
at the first step). Fixed in `9e57f2c` (`withTestId`, shared components expose their key) and
`828efb5` (nav tabs). Flows were also stale: the terms box starts checked (a tap unticked it),
the bio is on the About tab, `back` is Android-only, and one accessibility node holds a chat
message with its time and status.

and about ten sign-ins in a few minutes hit the backend rate limit ("Too many requests").
