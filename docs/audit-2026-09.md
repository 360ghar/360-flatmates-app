## 2. Findings by severity

### High
| ID | Finding | Location |
|---|---|---|
| M1 | Notification tap only stores a route; it is consumed on the next resume, bootstrap change or rebuild. A tap in the foreground can do nothing. | `lib/core/notifications/notification_service.dart:90-94,270-275`, `lib/app/app.dart:65-75,263-277` |
| M2 | `peerProfileProvider` is a non-autoDispose family, so one failed load stays cached for the session. The profile sheets show an error with no Retry. | `lib/features/chats/chats_repository.dart:459`, `flatmate_profile_sheet.dart:100-104` |
| M3 | Match Q&A sheet stacks text fields with no scroll; the shared sheet puts the keyboard inset inside the 85 % cap. RenderFlex overflow on small phones. | `lib/features/swipe/.../match_qna_nudge.dart`, `flatmates_bottom_sheet.dart:54-78` |
