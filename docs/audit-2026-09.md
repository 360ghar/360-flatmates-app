### Redesign

- Tokens, type, radius, elevation and motion from DESIGN.md in `lib/core/theme/`; old names are aliases, so every screen adopted the palette. Off-palette categorical colours collapsed into the clay and pine families.
- Gambarino bundled (no runtime font fetch); `google_fonts` removed.
- Paper primitives: `PaperSurface`, `PaperEdgeBorder`, `PaperScene`, `PaperSceneHeader`; grain tile `assets/paper/grain.png`.
- Components: paper buttons (press e2 → e1, secondary is a pine fill, bare icon button), cards, torn-edge sheets, scalloped toasts, `FlatmatesDialog` for every dialog (double-tap guarded), tone-pulse skeletons, scene-based empty/error/not-found, paper tab-strip nav with torn top edge and cut-paper `PaperIcon` tab icons, in-flow offline strip, web-matching wordmark ("360" clay + "Flatmates").
- Screens: splash, onboarding and auth use the scene, with scroll parallax on auth and onboarding (off under reduce motion); 8.1 MB of PNG art removed.
- Design-law sweep: no content starts at opacity 0 (page, empty, error, splash, match, staggered cards, profile menu groups all rise only), no tracked-caps labels (all-caps strings rewritten in sentence case), no accent word in headings, bare icons in rows and fact tiles, trust badges without pills, feathered scene edges, token shadows only, pine location dot.

### Remaining / next steps

1. Inner screens were checked with goldens and widget tests only; no test account was available (`MAESTRO_PHONE` unset). Run Maestro with credentials and review Discover, Swipe, Chats, Profile on device.
2. ~650 Material utility icons remain outside the tab strip; the settings menu does not use the paper icons yet.
3. 80 raw radii and 11 raw colours remain (ratcheted).
4. Launcher icon unchanged (brand decision, not part of this redesign).

### Deviations from plan

- Scene art ships as generated op-codes (`paper_art.dart`) drawn with `CustomPainter`, not SVG files with `flutter_svg` (no new dependency; the same generator feeds the web app).
- Grain is a tiled PNG through `DecorationImage` (`AssetImage`), not an `ImageShader` painter.
- Tokens adjusted for AA: clay `#A94A2B`, dark ink-3 `#A39C91`, clay-soft `#F6E6DE`.
- Launcher icon unchanged.
- M19 and M21 partly done (see table): full-list providers and the seeded listing notifier stay.
